# 按平 · can-i-delete 🔍

> Windows 上的证据优先缓存清理工具。只会**永久删除**内容已校验的缓存与崩溃转储；其他文件只分析、不删除。

## 当前能做什么？

- **递归分析文件夹**：遍历所选文件夹及其子目录，展示可获得的文件信息与判定线索。
- **暂停与继续**：扫描过程中可以暂停，再继续当前扫描；这些操作只控制扫描进度，不是清理操作。
- **查看详情**：点选结果条目查看详细信息和证据，结合路径、用途与不确定性逐项复核。
- **目录占用**：切换“目录占用”，按逻辑大小查看最大的子目录和文件，可逐层进入、返回上级和打开文件详情；只汇总已分析文件，不重复扫描，未进入及空目录不在列表中，目录页没有删除入口。
- **分页浏览**：结果按页显示；当前页不代表全部结果。扫描未结束或处于暂停状态时，已有结果也不能当作完整清单。
- **结束提示音**：首次使用默认关闭，点右上角喇叭开启；之后会记住开/关选择。自然扫描结束播放一次双音提示，最小化窗口也可播放；预算暂停、手动停止或整体失败不播放完成音。只控制应用提示音，不更改系统音量或输出设备。
- **清理**：扫描结束后打开清理清单，按三类分组选择，查看数量、逻辑大小、主要位置及后果；未选组不执行。崩溃转储默认不选，必须单独确认。永久删除不可恢复，显示进度，可以随时停止（当前这一项处理完就停）。

## 清理会删什么？

只删除下面三类、且每个文件都通过内容校验的文件：

| 类别 | 位置 | 校验 | 删除后果 |
| --- | --- | --- | --- |
| npm 包缓存 | `%LOCALAPPDATA%\npm-cache\_cacache\content-v2\sha512\` | 内容的 SHA-512 必须等于文件名 | 联网时 npm 会自动重新下载；**离线、私有源不可用或包已下架时将无法安装** |
| 缩略图/图标缓存 | `%LOCALAPPDATA%\Microsoft\Windows\Explorer\` 下的 `thumbcache_*.db`、`iconcache_*.db` | CMMM 文件头与条目偏移校验；索引文件 `*_idx.db` 不删 | 资源管理器自动重建，下次打开文件夹时预览稍慢。正被资源管理器占用的文件会跳过 |
| 崩溃转储 | `%LOCALAPPDATA%\CrashDumps\` | MDMP 文件头、流目录及每个数据流都必须落在文件内；内核转储不删 | **不能重新生成**：删除后无法再把这次崩溃报告发给软件厂商；不影响程序运行 |

- **永久删除，不经过回收站，不可恢复。**
- 「需复核」「建议保留」的文件永远不会被删除。
- 删除前会逐个重新核对：在独占打开的同一个文件句柄上核对文件身份、大小、修改时间，并重新校验内容，全部通过才删除。
- 会跳过的情况：文件被占用、扫描后被改动、被替换或已消失、存在多个硬链接。结果框会分别说明哪些未动、哪些已变化。
- 任何一项结果无法确认时立即停止后续删除，并锁定清理，重新扫描核对后才能再清理。
- 每次删除前后都强制写入审计日志：`%LOCALAPPDATA%\can-i-delete\delete-log.txt`。日志写不进去时停止清理。若上次清理中途崩溃或断电，下次启动会提示哪些文件需要核对，不会自动重试。

## 下载与运行条件

从 [Releases](https://github.com/Feli999ovo/can-i-delete-preview/releases) 获取完整发行包并解压，保留可执行文件旁的资源与依赖：

```text
can-i-delete/
├─ can-i-delete.exe
├─ WebView2Loader.dll
├─ lib/
└─ ui/
```

- **不是单文件、无依赖的 exe**：不要只复制 `can-i-delete.exe`；同目录的 `ui/`、`lib/` 和 `WebView2Loader.dll` 都应随完整发行包保留。
- Windows 必须已安装兼容的 **.NET Framework**；安装其他版本的 .NET 并不等于安装 .NET Framework。
- 默认的白瓷界面还需要已安装 **Microsoft Edge WebView2 Runtime**。
- 扫描本身不删除或修改文件；只有点「清理」并确认后才会删除。WebView2 会创建应用自身的用户数据与缓存。

满足运行条件后，双击 `can-i-delete.exe` 启动，选择文件夹开始分析，再通过暂停、继续、详情与分页查看结果。

### 经典只读界面（`--classic`）

可以通过命令行显式选择经典界面：

```text
can-i-delete.exe --classic
```

默认界面在未检测到 WebView2 运行时或 WebView2 初始化失败时，也提供切换到经典只读界面的提示。经典模式不依赖 WebView2 界面，但仍需要 .NET Framework；经典界面不执行删除。

## 如何理解证据与不确定性？

本工具提供复核线索，而不是对文件用途或删除后果的保证：

- 识别到某个来源、文件类型或常见临时目录，并不能证明文件已经无用。
- 文件较旧或未检测到占用，并不能证明删除安全；修改时间也不等于最后使用时间。
- 权限不足、读取失败、信息不足，以及扫描过程中目录或文件发生变化，都可能影响结果。未显示的项目不能视为不存在或已被完整检查。
- 对用途、归属或影响无法确认的项目，应保留不确定性并进一步复核，不应把推测当成事实。

请结合原软件的说明和自己的实际用途理解结果。清理只针对上表三类已校验的文件，**删除不可恢复**。

## 隔离的未来演示

开发预览用于展示未来界面流程，使用模拟数据，与正式扫描桥接隔离，不创建真实扫描或文件操作会话。

演示中即使出现勾选、清理、回收站或还原效果，也只是模拟：**不会删除真实文件。** 正式界面的清理是永久删除，不经过回收站或暂存。 预览本身需要 WebView2；初始化失败时会退出，而不会切换成真实扫描会话。
